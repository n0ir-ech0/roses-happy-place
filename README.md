# 🌹 Rose's Happy Place

A premium, magical happiness website made with love for Rose.

## 📁 Files

```
roses-happy-place/
├── index.html        ← Main website (all 11 pages)
├── style.css         ← All styles
├── script.js         ← All interactivity & data
├── rose1.jpg         ← Replace with Rose's photo
├── rose2.jpg         ← Replace with Rose's photo
├── rose3.jpg         ← Replace with Rose's photo
├── funny.gif         ← Replace with a funny GIF
└── README.md
```

## 🖼️ How to Add Photos

Replace the placeholder files with real photos:
- `rose1.jpg` — First photo of Rose
- `rose2.jpg` — Second photo of Rose
- `rose3.jpg` — Third photo of Rose
- `funny.gif` — A funny GIF for the Laugh Lab page

Just rename your files to match these names exactly.

## 🚀 Deploy to Vercel (Free)

1. Go to [vercel.com](https://vercel.com) and create a free account
2. Click **"Add New Project"**
3. Drag and drop the entire `roses-happy-place` folder
4. Click **Deploy**
5. Done! Share the link with Rose 🌹

## 🌐 Run Locally

Just open `index.html` in any browser — no server needed!
